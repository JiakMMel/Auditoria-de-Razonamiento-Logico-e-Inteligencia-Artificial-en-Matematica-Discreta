# Auditoria-de-Razonamiento-Logico-e-Inteligencia-Artificial-en-Matematica-Discreta
El objetivo de este proyecto es analizar y evaluar críticamente la capacidad de razonamiento simbólico, rigor formal y capacidad de prueba de los Grandes Modelos de Lenguaje (Se puso a prueba a ChatGPT, Gemini, Qwen) en los núcleos temáticos de Técnicas de Demostración, Funciones y Relaciones entre Conjuntos.
